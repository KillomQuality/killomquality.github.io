# killomquality.github.io

Резюме Егора Каплина (программист 1С) на GitHub Pages: https://killomquality.github.io/

Чистый HTML/CSS, без сборки — GitHub Pages публикует файлы как есть.

## Структура

- `index.html` — резюме (все стили внутри файла)
- `404.html` — страница «не найдено»
- `assets/style.css` — стили страницы 404
- `assets/favicon.svg` — иконка вкладки
- `.nojekyll` — отключает обработку Jekyll

## Как включить сайт

1. Влейте изменения в ветку `main`.
2. В репозитории: **Settings → Pages**.
3. **Source**: `Deploy from a branch`, **Branch**: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу https://killomquality.github.io/

## Как редактировать

Откройте `index.html` и замените тексты-заглушки на свои. Каждое изменение,
отправленное в `main`, автоматически публикуется.
